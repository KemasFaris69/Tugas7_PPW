CARA MENJALANKAN
1. Buka terminal di folder pmb-nusantara-frontend.
2. Jalankan npm ci.
3. Jalankan npm run dev.
4. Buka alamat yang ditampilkan Vite.
5. Fitur pengambilan data ada di bagian Informasi PMB.

PENGUMPULAN
1. Upload source aplikasi ke repository GitHub tanpa node_modules dan dist.
2. Kumpulkan link repository serta screenshot 01_Loading.png, 02_Success.png, dan 03_Error.png.
